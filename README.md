# Tokenizer
A simple Python script that reads a text file, applies two tokenizers (whitespace and regex based), and prints token statistics along with a comparison report.

Features
Whitespace tokenizer

Regex tokenizer with support for:
  punctuation,
  numbers & decimals,
  contractions,
  URLs,
  email addresses,
  hyphenated words,

Token statistics (total, unique, frequency)

Side by side tokenizer comparison
